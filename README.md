# 임한나의 AI 실습실 · 덕스 미래 아카데미

강의 때마다 함께 쓰는 실습 페이지입니다. GitHub에 고친 내용이 올라가면 Vercel이 1분 안에 자동으로 다시 배포합니다.

## 무엇을 어디서 고치나요?

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 강의 이름·날짜·장소·첫 안내 문구 | `config.js` 의 `LECTURES` |
| 강사 소개·링크 | `config.js` 의 `PROFILE` |
| 상하이 캠프 소개·신청 링크 | `config.js` 의 `CAMP` (`show: false`면 숨김) |
| 실습 문장(복사되는 문장), 탭 내용 | `index.html` |
| 색·글꼴 | `style.css` |
| 화면 동작 | `app.js` (보통 고치지 않음) |

## 강의별 주소

- 기본: `https://(배포 주소)/`
- 강의별: `https://(배포 주소)/?k=yangjae` — `config.js`에 적어 둔 이름을 `?k=` 뒤에 붙입니다.
- 페이지 오른쪽 아래 **QR** 버튼을 누르면 지금 보고 있는 강의 주소 그대로 QR이 나옵니다.

## GitHub 웹에서 고치는 법

1. 저장소에서 고칠 파일을 누릅니다.
2. 오른쪽 위 연필(✏️) 버튼 → 내용 고치기
3. **Commit changes** 버튼 → 1분쯤 뒤 페이지에 반영
